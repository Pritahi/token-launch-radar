A token launch radar: reads a sealed DefiLlama snapshot of 758 protocols, ranks the ones with no token yet by implied launch value, and shows how to farm each one, as an offline dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
